# Deflationary-Currency
A deflationary currency that is hard capped at 10 quadrillion units. It is also divisible fractionally in the decimals infinitely. 
-------------------------------------------------------------------------------------------------
I propose an open source deflationary currency that doesnt require electricity to be made or minted. So the currency has built in scarcity by being hard capped at 10 quadrillion. No more no less. It has fractionals of itself to the infinite. Basically since we cant ever run out of decimal places we can have an infinitely deflationary currency.
The hard capped currency can have the value of each unit grow in value especially long term as more people buy the currency and use it. The more people there are that use it the less units there are to have but the value goes upwards long term.
People can convert their fiat or any other currency to this hard capped currency. It wouldnt need to be mined or minted it just exists digitally. The value given is given by the amount transferred for it by other currencies.
There would need to be a public ledger like the blockchain in bitcoin so we can verify that there is not duplications of any single unit. There would have to be a built in transfer upon death to relatives or designated people to have the currency. 
We cant measure infinity but we can put a place holder of where each decimal number of each unit is worth. so if say you had .1 units and 1 unit was worth $1 it would be worth 10 cents. At 0.01 units it would be worth 1 cent. at 0.001 it would be worth a tenth of a cent and so on.
If for some reason our current technology cant make it infinite we can hard cap it as we go along in the decimals from one decimal to the next decimal as technology advances. It would be more like a soft cap until further tech advancement happens. I wouldn't advice lending this type of currency
since lending this currency will make the one who took the debt owe more every time and their ability to reach that amount of debt to be paid would be harder and require more. If a lending service existed that did such a thing it would basically be predatory and unethical.
This currency would be like a buy and hold currency or asset. The amount that it would go up in value depends entirely on how much trading volume and conversions of other currencies to this currency happen. If there are trading fees implemented from a currency to this one then this currency will
gradually grow in value based off the trading fees as well. You can also Use the currency as a medium of exchange if you want. Either a store of value, or both a medium of exchange as well. I am sure that people might find a way to increase the uses for it besides those too.
